# 🎯 wkl CS2 灵敏度生成器

> 通过 3 项专业鼠标测试，科学计算你的最佳 CS2 灵敏度

** 在线体验：https://2432448868.github.io/**

---

## 功能特性

### 三项专业测试

| 测试 | 时长 | 说明 |
|------|------|------|
| 🎯 **追踪测试** | 15s | 鼠标跟随移动目标，不需要点击，碰到即计分。测试追踪稳定性 |
| 🔫 **精准度测试** | 25s | 点击随机出现的目标，测试定位速度和点击精准度 |
| ⚡ **微调测试** | 20s | 从中心点出发快速点击近距离目标，测试精细控制力 |

### 结果输出

- **推荐 CS2 灵敏度**：直接输入游戏控制台即可使用
- **eDPI**：DPI × 灵敏度的综合指标
- **cm/360°**：鼠标转一圈的移动距离
- **多 DPI 对照表**：400 / 800 / 1000 / 1200 / 1600 / 3200 灵敏度换算
- **推荐范围**：±15% 浮动区间，方便微调
- **个性化建议**：根据每项测试得分给出针对性改进建议

## 灵敏度计算原理

### 评分模型

```
综合分 = 追踪得分 × 35% + 精准度得分 × 30% + 微调得分 × 35%
```

### 灵敏度映射

| 综合分 | 推荐 eDPI 范围 | 适用风格 |
|--------|---------------|----------|
| 80-100 | 500-800 | 低灵敏度精准流，适合追踪能力强的玩家 |
| 60-79 | 800-1100 | 中低灵敏度均衡流 |
| 40-59 | 1100-1400 | 中等灵敏度成长向 |
| 0-39 | 1400-1800 | 中高灵敏度速度流，弥补控制不足 |

### CS2 灵敏度公式

```
eDPI = DPI × sensitivity
cm/360° = (360 / (sensitivity × DPI × 0.022)) × 2.54
```

> 其中 `0.022` 是 CS2 的 yaw 值，与 CS:GO 一致。

## 使用方式

1. 打开 https://2432448868.github.io/
2. 输入你的鼠标 DPI（可在鼠标驱动软件中查看）
3. 依次完成 3 项测试
4. 获取推荐灵敏度，输入 CS2 控制台：
   ```
   sensitivity 1.23
   ```

### ⚠️ 测试前准备

- **关闭 Windows 鼠标加速**：控制面板 → 鼠标 → 指针选项 → 取消勾选「提高指针精确度」
- 使用你日常玩 CS2 时的鼠标和鼠标垫
- 测试中使用最自然的握鼠姿势，不要刻意控制

## 技术实现

- **纯前端**：单 HTML 文件，零依赖，无需后端
- **追踪测试**：Canvas 渲染 + Lissajous 曲线目标运动 + 鼠标悬停检测
- **精准度/微调测试**：DOM 目标 + 点击事件 + 反应时间记录
- **准星渲染**：`requestAnimationFrame` + CSS `transform` 实现零延迟跟手
- **部署**：GitHub Pages + GitHub Actions 自动构建
